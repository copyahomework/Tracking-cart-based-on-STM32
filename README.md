## 一、项目概述
本项目通过STM32F103C8T6为主体，实现遥控寻迹小车，主要功能有：
- 通过蓝牙串口通讯进行遥控，使小车运动
- 通过灰度传感器接收灰度值，使其完成循迹功能
- 通过按钮检测小车电机运转情况（方便测试之用）
- 通过OLED显示屏显示小车运行情况和接收到的灰度值

## 四、功能概述
### 1.非线性转换与LED指示
该项目使用LED显示小车运行状态，当小车处于静止状态时，LED灯常亮；当小车处于运动状态时，LED灯熄灭；当按钮被按下时，PC13LED灯随按钮状态进行亮灭（当按钮按下时PC13LED熄灭，抬起时PC13LED亮起），用于测试小车状态是否正常

### 2.显示功能
当小车上电后，OLED显示屏会显示“HELLO！”字样，提示小车正常上电，同时显示灰度传感器值并不断刷新。当小车处于按键检测状态时会先显示“LOADING~~”字样，后显示测试项目。

### 3.按键功能
当小车出现故障时，方便定位小车问题原因，故加入按键调试功能。当按键按下时，OLED显示“LOADING~~”，表面小车进入按键检测状态；长按按键后，小车电机全部正转，LED灯熄灭；双击按键后，小车电机全部反转，LED灯熄灭；单击按键后，电机全部停止，LED灯闪烁三下后常亮，OLED显示"TEST FINISHED"，小车退出按键调试状态，进入遥控状态。

### 4.小车初始状态
上电初始状态为LED灯常亮，OLED屏首行显示“Hello!”字样，后三行分别显示灰度传感器值。

## 五、基础配置
==本项目配置由STM32CubeMX配置==
### 1.GPIO
```C
PA7 普通推挽输出 上拉
PC13 输入模式 上拉
```

### 2.NVIC中断配置
```C
蓝牙串口需要配置USART中断
TIM2需要配置定时器中断
```

### 3.PWM配置
本项目使用了定时器2的通道1、2、3、4，定时器3的通道3、4，定时器6的通道3、4输出PWM驱动直流电机作为小车动力源，需要配置相应的TIM。所有PWM的Prescaler为72-1，Period为100-1；每两个通道控制一个直流电机，一个通道负责正转，一个通道负责反转；通过修改 CCR 比较值来调占空比，从而调电机速度。

### 4.I2C输出配置
I2C频率设置为100000Hz。

### 5.USART配置
蓝牙和串口的波特率全部要设置为9600 Bits/s，字节长度8Bits，无校验位，1停止位；

### 6.其余配置
1. 电源模块：电源模块要将输出电源分别调整为3.3v输出和5v输出，并确保正负极接线正确。
2. 其他元器件：其他元器件保证接线正确。
